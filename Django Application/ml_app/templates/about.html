About Fake Video Content Detection

This application analyzes uploaded videos to estimate whether content is likely real or fake using deep learning. It processes frames, detects facial regions, and runs inference with a ResNeXt + LSTM model.

Workflow

Upload video → extract frames → detect faces → run model inference → show confidence.

Model Input

The selected model determines the configured frame count used during prediction.

Output

The result includes predicted class (REAL/FAKE), confidence score, and processed previews.

Tip

Use clear frontal-face videos for better detection quality and more stable confidence scores.
